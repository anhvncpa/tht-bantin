# Nhạc sôi động cho video chữ chuyển động

Bỏ file nhạc (.mp3, .m4a) **có bản quyền dùng thương mại** vào thư mục này (ví dụ nhạc miễn phí từ Mixkit, Pixabay Music, YouTube Audio Library).
Khi thư mục có nhạc, video bản tin ưu tiên dùng nhạc ở đây; nếu trống, bot dùng các bài `kich-tinh-*`, `hien-dai-*` trong thư mục music/.
Hiệu ứng âm thanh (whoosh, pop, tick, impact) bot tự tạo, không cần file.
